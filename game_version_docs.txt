🐾 動物保衛戰 (Animal Tower Defense) - 遊戲版本說明文件
==================================================

【遊戲簡介】
《動物保衛戰》是一款採用原生 HTML5 Canvas 與現代 JavaScript (ES6+) 開發的單一檔案 2D 塔防遊戲。玩家需要在左側的食物防線前部署動物夥伴，抵禦 15 個回合不斷來襲的猴子大軍。

【核心功能與機制】
1. 畫面佈局：
   - 左側：食物防線（🍕），為猴子進攻的終點目標。
   - 中間：4 行 x 8 列的戰術放置格子（Grid）。
   - 右側：猴子生成區與進攻路徑。
   - 上方 UI：即時顯示當前回合（Wave 1 ~ 15）、當前飼料數量（🍖）與遊戲狀態訊息。
   - 下方控制區：提供動物召喚按鈕（含冷卻遮罩與資源不足自動禁用狀態）以及自訂速度設定選單。

2. 角色與單位設定：
   - 🍕 食物（Food）：位於最左側，若任意猴子觸碰即遊戲失敗。
   - 🐰 兔子（Rabbit）：
     * 召喚消耗：1 個飼料。
     * 功能：資源生產單位。每隔固定時間自動產生 1 個飼料（時間可自訂）。
   - 🦁 獅子（Lion）：
     * 召喚消耗：2 個飼料。
     * 功能：攻擊單位。每隔固定時間對同一橫道的猴子發射香蕉子彈（🍌）（時間可自訂）。
   - 🐹 水豚（Capybara）：
     * 召喚消耗：3 個飼料。
     * 功能：高血量防禦單位，可阻擋並擊退猴子。
   - 🐱 貓咪（Cat）：
     * 召喚消耗：5 個飼料。
     * 功能：攻擊單位，每次發射兩個蘋果子彈（🍎）（時間可自訂）。
   - 🐵 猴子（Monkey）：
     * 敵人單位。從畫面右側生成並緩慢向左移動。
     * 普通猴子血量：5（遭受 5 次攻擊後消失）；特殊猴子依類型具有不同血量與速度。

3. 自訂參數選單（新功能）：
   - 🐰 兔子產資源間隔：支援下拉選單隨時設定（0.5 秒起跳：0.5s / 1.0s / 1.5s / 2.0s / 3.0s）。
   - 🦁 獅子攻擊間隔：支援下拉選單隨時設定（0.5 秒起跳：0.5s / 1.0s / 1.5s / 2.0s / 3.0s）。
   - 🐱 貓咪攻擊間隔：支援下拉選單隨時設定（0.5 秒起跳：0.5s / 1.0s / 1.5s / 2.0s / 3.0s）。

4. 召喚冷卻機制（新功能）：
   - 每次點擊召喚動物後，按鈕會觸發冷卻時間，並在按鈕上顯示半透明的動態冷卻遮罩。

5. 回合與勝負判定：
   - 總計 15 個回合（Wave 1 ~ Wave 15）。
   - 隨著回合數增加，猴子數量與進攻速度逐漸提升。
   - 勝利條件：清空第 15 回合所有猴子後顯示「勝利！」畫面。
   - 失敗條件：任何一隻猴子觸碰左側食物防線時立刻顯示「遊戲失敗」畫面。

【技術堆疊】
- 僅使用原生 HTML5、CSS3 與 JavaScript (ES6+)。
- 內含 Emoji 與 Canvas 2D 繪圖，無需任何外部圖片或第三方套件支援。
- 程式碼全部收錄於單一檔案：animal_tower_defense.html。
